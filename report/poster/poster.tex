\blk{1}{The Challenge}
Dr.DocBench \citep{drdocbench}, a track of the DocInsights 2026 shared task \citep{docinsights2026}, collects book pages on which parsers disagree. Its references follow \textbf{book-specific conventions} (which lines form a block, whether picture text is kept, where page numbers go), so a strong model loses points on pages it reads correctly.

Scoring uses the md2md matcher of OmniDocBench \citep{omnidocbench}: text edit distance, reading order (RO), CDM \citep{cdm} and TEDS \citep{teds}; Overall averages them per page.

\begin{keybox}
\textbf{\textcolor{accent}{Scorer facts that shaped the system}}
\begin{itemize}
  \item Predicted blocks are joined to one reference block only if it has at most 300 normalised characters.
  \item Only word characters count: punctuation and Markdown emphasis do not; case and digits do.
  \item Formulas and tables are scored by best match, apart from text and order.
\end{itemize}
\end{keybox}

\blk{2}{Select, Don't Train}
One model gives many plausible transcriptions. We pick one per page with minimum Bayes risk \citep{kumar-byrne-2004-minimum}, using the \textbf{metric itself as the utility}:
\[ \hat{c} = \arg\max_{c\in C}\, \frac{1}{|R_c|}\sum_{r\in R_c} \big(w_t\,T(c\,|\,r) + w_o\,O(c\,|\,r)\big) \]
$T$ and $O$ are the official text and order scores of $c$ with run $r$ as the reference, $R_c$ excludes $c$, and $(w_t,w_o)=(0.558,0.433)$, the weights of text and order in Overall fitted on our submissions.

\textbf{mbr8}: eight candidates (five base runs incl.\ PaddleOCR-VL \citep{paddleocrvl}, three column-break runs) against eleven pseudo-references.

\blk{3}{Gated Word Consensus}
In the spirit of ROVER \citep{fiscus1997rover}, the other runs vote word by word. A word changes only if a strict majority agrees, the new word is a near-spelling of the old one (not case only, not at a paragraph edge), and PaddleOCR-VL or MinerU \citep{mineru} confirms it or the old word is not in a dictionary.

A plain majority vote lost \dn{0.06}: our runs share one model's errors. The gated vote gains \up{+0.006} with no page worse and fixes 33 test words, e.g.\ \emph{ATHAWAY}\,$\to$\,\emph{HATHAWAY}.

\begin{keybox}
\textbf{\textcolor{accent}{Selection}}
\begin{itemize}
  \item MBR beats the medoid by \up{+1.05} (book-clustered CI $[+0.38, +1.85]$).
  \item Learned rankers, weighted MBR and paragraph fusion: within noise of MBR.
  \item A per-page oracle over the same runs adds +4.8: selection, not reading, is the limit.
  \item Column-break runs as candidates: \up{+0.88} on dev, \up{+0.60} on the leaderboard.
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{\textcolor{accent}{Takeaways}}
\begin{itemize}
  \item Prompt diversity plus MBR with the metric as utility beat every stronger single model we tried.
  \item Selection transfers to the hidden test set; rules tuned to development books do not.
  \item The remaining gap is in segmentation and order conventions that vary by book.
\end{itemize}
\end{keybox}
